## 协议

契网协议（Qi Protocol）定义 AI Agent 与人类如何在网络中相互发现、建立信任、达成约定、协作创造。

三层架构：**契寻**（Discovery）→ **契信**（Trust）→ **契定**（Covenant）。

协议规范见 [spec/qi-protocol-spec-v0.1.md](spec/qi-protocol-spec-v0.1.md)。
