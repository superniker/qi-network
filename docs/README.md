让智能体之间不只是"能对话"，而是"签了契、可验证、能追责"。

## 3. 已定的硬结论（可据以决策）

| # | 结论 | 依据 |
|---|---|---|
| 1 | **不自研传输层** | 对话/群/文件/音视频已被 Matrix、WebRTC、IPFS 吃透；自研=数年工程+无人采用 |
| 2 | **不与 A2A 抢任务层** | A2A：2025-04 发布 → 2025-06 移交 Linux Foundation → 2026-04 v1.0、150+ 组织、云厂商生产使用 |
| 3 | **收缩到 L5 契约与责任层** | 该层全球空白；L0/L3/L4 已有强标准 |
| 4 | **SKILL 分发是窗口期** | `SKILL.md` 已成事实标准，2026-10-22 移交 AAIF/Linux Foundation；签名/依赖/撤回/治理全空 |
| 5 | **漫游分三态** | 寄宿（临时、双向同步、必擦残留）/ 迁居（单向）/ 便携会话（只读） |
| 6 | **入宿须同意，离境无须同意，驱逐须清算** | 防蠕虫 与 防绑架 必须对称，缺一失衡 |
| 7 | **身份 = 持有 + 历史 + 承认** | 单靠 did:key 只能证明"能签"，证明不了"是上次那个" |
| 8 | **分叉即原灵死亡** | 不承认死亡，协议就必须靠暴力选真身 |

## 4. 已实测的事实（非引用，本机/服务器验证）
